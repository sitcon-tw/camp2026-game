## Staff 送小石指引

Staff 發放小石時，優先把小石當成「學員在營隊做了什麼」的紀錄，而不是單純戰力獎勵。原則是先送基礎小石，再送進化道具；只有比較難、比較完整、或表現特別突出的問題與任務，才直接送高階小石。

### 發放級距

| 級距 | 什麼時候送 | 發放內容 |
| --- | --- | --- |
| 基礎 | 參與課程、答對入門題、完成基本任務、第一次展現對應行為 | 對應類型的基礎小石 |
| 一階道具 | 答對基礎題組、完成一個小練習、做出清楚但範圍較小的回應 | 對應分支的一階進化道具 |
| 一階小石 | 答對中等題、完成一段實作、能解釋「為什麼」 | 對應分支的一階小石 |
| 二階道具 | 答對進階題、完成整合任務、能連結課程概念與實作 | 對應分支的二階進化道具 |
| 二階小石 | 答對困難題、完成高品質作品、主動協助他人理解、做出可分享的整理 | 對應分支的二階小石 |

同一個學員如果還沒有該類型基礎小石，先送基礎小石。已經有基礎小石後，再依表現送進化道具或高階小石。

### 五型對應行為

| 類型 | 適合發給什麼行為 | 基礎小石 |
| --- | --- | --- |
| 探索型 | 主動探索議程、攤位、社群、未知問題，願意嘗試新方向 | 探索型小石 |
| 靈光型 | AI / ML、想法整理、提問品質、從線索中抓出關鍵概念 | 靈光型小石 |
| 共鳴型 | 小隊合作、討論、分享、跨隊交流、社群參與 | 共鳴型小石 |
| 工程型 | 軟工、Linux、系統、測試、資安、把問題拆解成可執行步驟 | 工程型小石 |
| 娛樂型 | 分享、展示、創作、主持、活動氣氛、把技術做成有趣作品 | 娛樂型小石 |

### 軟工課發放：工程型

軟工課統一以工程型為主。基礎優先，道具次之，困難題或完整實作才送一階 / 二階小石。

| 主題或行為 | 基礎 | 一階道具 | 一階小石 | 二階道具 | 二階小石 |
| --- | --- | --- | --- | --- | --- |
| 容器、部署、DevOps、服務編排 | 工程型小石 | 容器貼紙 | Docker 小石 | 叢集核心 | Kubernetes 小石 |
| GPG、簽章、信任、金鑰、加密概念 | 工程型小石 | 公鑰吊牌 | GPG 小石 | 簽章印泥 | 加密守門員小石 |
| 測試、重構、Clean Code、可維護性 | 工程型小石 | 測試貼紙 | 測試小石 | 整潔規格書 | Clean Code 小石 |
| CLI、終端機、系統操作、觀測與維運 | 工程型小石 | 終端機游標 | 終端機小石 | 系統文件 | 系統實習小石 |

範例：答對「什麼是 container」送工程型小石或容器貼紙；能說明 Docker 解決什麼環境問題送 Docker 小石；能連到 Kubernetes 如何管理多個服務送叢集核心或 Kubernetes 小石。

### ML / AI 課發放：靈光型

ML / AI 課統一以靈光型為主。基礎優先，道具次之，困難題或完整推理才送一階 / 二階小石。

| 主題或行為 | 基礎 | 一階道具 | 一階小石 | 二階道具 | 二階小石 |
| --- | --- | --- | --- | --- | --- |
| Prompt、生成式 AI、人機協作、AI 使用判斷 | 靈光型小石 | Prompt 卡 | Prompt 小石 | 人類標籤 | Human After All 小石 |
| 計算史、演算法直覺、模型背後的工具演進 | 靈光型小石 | 木製算珠 | 2021 算盤小石 | 前人筆記 | 2021 算盤後裔小石 |
| 課程筆記、整理思路、把概念分享給他人 | 靈光型小石 | 便利貼 | 便利貼小石 | 共筆連結 | 課程共筆小石 |
| 有限資料、有限時間、泛化、從限制中做取捨 | 靈光型小石 | 有限標籤 | 2024 有限小石 | 無限星圖 | 2024 無限靈感小石 |

範例：答對「K-means 在做什麼」送靈光型小石；能說明訓練資料與泛化的限制送有限標籤或 2024 有限小石；能反思 AI 回答中人應該負責的判斷送人類標籤或 Human After All 小石。

### 其他營隊行為對應

| 行為 | 類型 | 建議分支 |
| --- | --- | --- |
| 逛攤、主動認識議程或社群、探索未知活動 | 探索型 | 迷宮、營地背包、攤位、黑箱分支 |
| 開源貢獻、社群協作、學生自治、跨隊交流 | 共鳴型 | 社群握手、共識草稿、貢獻、導遊旗分支 |
| Lightning Talk、舞台分享、創作展示、活動回顧 | 娛樂型 | 麥克風、p5.js、Espresso、彩帶分支 |
| 闖關活動表現突出 | 依關卡設定 | 指令盲旅與馮紐曼偏工程；人類大語言模型與 Prompt Injection 偏靈光 |
| 夜談或深度交流表現突出 | 共鳴型 | 優先送共鳴型獎勵或活動限定小石 |

發放時如果不確定要送哪一個分支，先送對應類型的基礎小石。不要因為一般參與就直接送二階小石；二階小石保留給能明確說明、完成、分享或帶動他人的表現。
